# Önbizalom-kurzus

9 modul, 81 lecke (Alap, Közép, Mester szint), magyarul. Minden leckében tananyag, időzített gyakorlat, naplókérdések, mérföldkő és AI-tanár prompt.

**Live:** https://jtdevzero.github.io/onismeret/onbizalom-kurzus/ (ideiglenesen az onismeret repóban; a kód független, külön repóba költöztethető)

- Statikus oldal, build nélkül: `index.html`, `assets/`, `modules/m1–m9.js` (a leckék tartalma), `fonts/` (helyi Cardo és Inter, SIL OFL).
- A haladás és a napló csak a böngésző localStorage-ában tárolódik (`onbizalom-kurzus-v1`); export Markdownba, mentés és visszaállítás JSON-fájllal.
- Új lecke vagy javítás: a megfelelő `modules/mN.js` fájlban.

Önfejlesztő anyag, nem terápia. Készítette: JT, Budapest, 2026.
